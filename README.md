# Fatigue Event

I would like to create an app for an airlines, I would like app that help me calculate Fatigue Event and give me the entries that are needed , the calculation will be from input data like   Bid Status: Line Holder or RSV on PR/OG , Reserve on RSV Flying, Time of Fatigue: hhmm, Sign in time:hhmm, Back for Duty: ddmm / hhmm, FEM completed: yes or no, if not this needs to be completed before processing. I can give you the steps and the entry base of the result of the calculation and scenario .
